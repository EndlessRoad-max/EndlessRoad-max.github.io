笔记约定

记法约定

每个章节文件放在对应篇章目录下，命名 01-xxx.html；同一章的知识点按课程小节顺序排列，不复述视频原话，只保留"能复用的结论 + 能跑的 SQL"。

每页固定三段：开头一屏速记（5 条以内，合上笔记能复述）→ 中间图解 + 可跑命令（讲清为什么）→ 结尾自测三问（折叠答案，先答再看）。速记负责复习，正文负责理解，自测负责记住。

版本注意

课程部分章节录制于 MySQL 5.7 环境，涉及 utf8mb4、窗口函数、CHECK 约束生效等差异时，笔记按 8.0 行为标注。
