## 想解决的问题

项目散落在不同仓库里，笔记也没有统一的阅读入口。这个示例展示了如何通过个人网站把二者组织起来。

## 核心功能

- 首页介绍个人方向，展示精选作品。
- 使用 Markdown 管理项目介绍与技术笔记。
- 通过全文搜索快速找到过去的记录。

## 实现思路

使用 Astro 在构建时生成静态页面。内容随 Git 仓库版本管理，构建通过后由 GitHub Pages 托管。
