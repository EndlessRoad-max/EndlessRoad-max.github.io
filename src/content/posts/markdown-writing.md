> 这篇示例用于检查 Markdown 的排版和代码复制功能。

## 写下清晰的结构

用二级标题组织主题，用三级标题展开细节。正文尽量保持短段落，让阅读有停顿，也方便以后补充。

### 代码也有上下文

代码之前写清楚目的，代码之后说明结果。读者应该知道这段代码解决什么问题。

```typescript title="hello.ts"
const notebook = {
  title: "我的第一篇笔记",
  tags: ["学习", "实践"],
};

console.log(`开始记录：${notebook.title}`);
```

## 用表格比较信息

| 内容 | 适合的形式 | 维护方式 |
| --- | --- | --- |
| 项目经历 | 项目详情 | 补充截图与复盘 |
| 学习过程 | Markdown 笔记 | 持续更新 |
| 个人介绍 | 关于页面 | 修改个人配置 |

## 保持记录可检索

给文章一个具体的标题，并填写摘要和标签。搜索“Markdown”可以重新找到这篇文章。
